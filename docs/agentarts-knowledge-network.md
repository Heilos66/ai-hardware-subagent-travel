# AgentArts 文旅智能体知识库网络调研

核实日期：2026-10-10。仅采用华为云官方资料；未登录云控制台、未测试真实网络或修改部署。

## 结论

**知识库并非只能开公网。当前项目采用高代码运行时，可以通过私网连接直接调用检索服务 API；低码自带的第三方知识库连接器需要另行区分。**

| 接入方式 | 已核实的网络能力与限制 |
| --- | --- |
| 高代码运行时，由应用代码调用检索 API | 官方运行时部署配置支持“私网访问”，选择 VPC、子网、安全组，访问内部资源和服务。此能力可用于私网中的知识检索服务；服务必须实际可路由到达。[运行时部署](https://support.huaweicloud.com/highcode-agentarts/agentarts_10_031.html) |
| 低码第三方 General 连接器 | 准备步骤明确要求服务接口发布到公网且可访问；不能把填写内网 URL 当作已支持的方案。[General 连接](https://support.huaweicloud.com/highcode-agentarts/agentarts_05_0245.html) |
| 低码第三方 RAGFlow 连接器 | 官方要求连接失败时检查 RAGFlow 是否支持公网 API 访问；未查到该连接器绑定用户 VPC 的官方配置。[RAGFlow 连接](https://support.huaweicloud.com/highcode-agentarts/agentarts_05_0166.html) |
| AgentArts 平台知识库组件 | 官方限制平台知识库和平台接入的第三方知识库只用于低码智能体，不能在托管运行时或 Managed Agent 中直接使用。[创建知识库](https://support.huaweicloud.com/highcode-agentarts/agentarts_10_207.html) |

因此，当前项目的私网方案是 **Java 服务直接请求 RAGFlow 检索 API**，而不是在高代码运行时中复用低码“知识检索”组件。当前已实现 [RAGFlow 接入](ragflow-travel-agent-integration.md#本工程接入与验证)，配置模板使用 `http://172.16.0.154:9380/api/v1/retrieval`。RAGFlow 已通过本地模拟测试，本机真实请求仍在 HTTP 响应前被断开，不能据此宣称现网私网已经可用。

## 建议部署与验证

2026-10-12 用户补充公网入口 `1.95.220.19:9380`。当前代码使用环境变量 `RAGFLOW_URL` 指定完整检索地址，可配置私网 `http://172.16.0.154:9380/api/v1/retrieval` 或公网 `http://1.95.220.19:9380/api/v1/retrieval`，无需更换镜像。环境变量更新后重启进程，或发布/切换 AgentArts 运行时配置；真实检索需保持 `RAGFLOW_ENABLED=true`。本次未验证新公网入口的连通性与鉴权。配置示例见 [环境变量说明](environment-variables.md#公网与私网地址切换)。

以下为基于上述产品能力的工程建议，不是已经验证的部署结果：

1. 优先把运行时出网 VPC 与检索服务安排在同地域、同 VPC，选择子网和安全组，检查 DNS、路由、目标服务端口及认证。
2. 核对 RAGFlow 服务的私网检索 URL，配置应用直接调用；不要仅把公网域名替换成猜测的私网 IP。
3. 若模型、分类器仍使用公网地址，还需验证运行时切换私网后这些依赖的访问路径，不能默认公网访问继续可用。
4. 若“内网”指景区或企业机房，须先建立到云 VPC 的连接；不能直接填机房 `192.168.x.x` 地址就期望可达。专线可构建本地与云 VPC 的专用连接；具体资源、地域和路由需按部署确认。[云专线服务说明](https://support.huaweicloud.com/bulletin-dc/dc_bulletin_0004.html)

## 内网是否更快

**同地域私网通常是更值得优先验证的路径，但不能承诺整体问答一定明显提速。** 此为工程分析：网络仅占检索耗时的一部分，向量化、召回、重排、服务排队以及模型生成也会影响用户等待时间。经互联网 VPN 接入的企业“内网”，也不能视作同地域云私网或纯专线。

建议以同一检索服务、相同问题、相同 TopK/重排配置和并发，对公网与私网进行对照；分别统计检索耗时 P50/P95、失败率、首字时延和整轮耗时，并区分冷启动与预热状态。真实检索性能应使用实际服务测量。
