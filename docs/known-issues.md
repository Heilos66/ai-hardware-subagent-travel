# 遗留问题

## KI-001：空知识上下文的回答边界不一致

- 记录日期：2026-10-14
- 状态：待修复，仅记录问题与方案，尚未修改业务代码。
- 范围：知识检索结果、提示词构建和检索诊断；保留现有图片分类与模型选择分支。

### 问题与影响

系统提示要求展品资料未明确说明时回答无法确定，空知识上下文的附加提示却笼统允许使用可靠常识。两者的适用范围不够明确，模型可能用通用知识补全具体展品的年代、出土地点、馆藏身份等未经资料支持的事实。

这是提示词边界存在歧义的代码层面问题，不代表已通过真实模型复现了错误回答。

### 当前实现

依据：[Prompts.java](../src/main/java/com/travel/agent/Prompts.java)、[TravelAgent.java](../src/main/java/com/travel/agent/TravelAgent.java)、[RagFlowClient.java](../src/main/java/com/travel/agent/RagFlowClient.java)、[WorkflowDiagnostics.java](../src/main/java/com/travel/agent/WorkflowDiagnostics.java)。

| 位置或场景 | 当前行为 |
| --- | --- |
| 系统提示：展品相关问题 | “优先依据提供的展品资料准确回答；资料没有明确说明时，说明无法确定，不得编造。” |
| 系统提示：展品之外的问题 | 可以回答已知的一般事实，但保持简洁，不进行复杂推理、延伸分析或主观建议 |
| 文本模型，有可用知识上下文 | 要求结合内部资料回答，不提及资料的存在或来源 |
| 文本模型，无可用知识上下文 | “当前没有可用的内部资料，请基于可靠常识谨慎回答，无法确认的信息请明确说明。” |
| 图片分类达到阈值 | 按分类名称检索，向文本模型提供分类候选名称，要求先自然介绍景点或展品名称；不再传原图，这是预期行为 |
| 视觉模型分支 | 使用统一系统提示、原图和用户问题，不附加上述空知识提示，也不进行知识检索 |
| 关闭检索、零命中、过滤后为空 | 都可能向后续流程提供空片段列表，提示词构建层无法直接区分来源 |
| 当前诊断 | 已有 ragflow_skipped，以及返回数、保留数和 empty_result，可辅助区分原因；尚未将其统一建模为传递到业务层的检索状态 |
| 检索服务报错 | 明确失败并停止模型调用，不按空知识处理 |
| 回答约束 | 主要依赖提示词，没有对事实依据、内容类别或字数进行程序化校验 |

### 拟定修复方案

#### 1. 统一回答规则

- 通用知识问题：允许基于可靠常识简洁回答。
- 具体展品事实：年代、出土地点、馆藏身份等必须有资料明确支持；没有依据时说明无法确定，不根据外观或常识猜测。
- 混合问题：回答有依据的部分，对其余部分说明无法确定。
- 有检索结果不代表问题已有答案：资料未提及或不相关时，同样不能推测具体事实。
- 分类名称只作为候选线索，不单独证明具体展品的身份或历史信息。
- 不向用户展示内部检索状态，沿用现有语言、简洁表达及输出格式要求。

删除空上下文时笼统的“基于可靠常识回答”指令，改为与系统提示一致的规则。视觉分支可描述可见内容，但不能仅凭图片确定缺乏依据的历史事实。

问题类型由模型根据统一提示词判断，不额外增加模型调用，也不采用关键词硬分流。提示词调整不能保证模型完全遵守，需通过真实模型样本验收。

#### 2. 明确检索结果状态

由 RagFlowClient 返回“片段＋状态”，通过 ExternalServices、TravelAgent 传递到 Prompts，并在诊断日志中记录。

| 状态 | 含义 |
| --- | --- |
| disabled | RAGFLOW_ENABLED=false，没有实际查询 |
| no_hits | 检索成功，返回的原始 chunks 为空 |
| filtered_empty | 原始 chunks 非空，但经过非空正文、相似度等规则过滤后没有可用片段 |
| available | 存在可用片段；不表示这些片段一定能回答当前问题 |

日志保留原始返回数与保留数，明确记录状态。视觉分支本身不检索，不应标记为 no_hits。检索业务错误、超时、连接或格式异常继续走现有失败流程，不转换为空结果，不自动降级为常识回答。

### 验收要点

1. 自动化测试区分 disabled、no_hits、filtered_empty、available；检索异常仍返回失败，不调用模型。
2. 验证各相关分支生成的提示词没有互相冲突的指令；保留高置信度图片分支不传原图的行为。
3. 用真实模型分别验证普通常识、具体展品事实、混合问题、有资料但资料不相关、资料明确支持答案等场景。
4. 示例：无资料时问“这件青铜器出土于哪里？青铜是什么？”，预期说明无法确认该展品的出土地点，同时可回答青铜的一般定义。
5. 分开记录自动化测试与真实模型评测结果；不能仅凭提示词字符串断言通过就认定事实边界已得到保证。
